# AstroWar: Lunar Chaos — Portal oficial

Juego 3D de artillería por turnos en la Luna, desarrollado en Unity 6 por el equipo **Warlings**
(Game Development · Evaluación final 2026).

**Jugar:** https://andremka.github.io/AstroWar/

## Estructura
| Carpeta / archivo | Contenido |
|---|---|
| `index.html` | Página del portal |
| `css/estilos.css` | Estilos |
| `js/portal.js` | Carga del juego, tráiler, GDD y carrusel (configuración al inicio del archivo) |
| `juego/` | Compilación Web (WebGL) exportada desde Unity |
| `media/trailer.mp4` | Tráiler (opcional si se usa YouTube) |
| `docs/GDD_AstroWar_Lunar_Chaos.pdf` | GDD final |
| `assets/` | Logo, íconos, tutorial y tipografías (Orbitron y Fredoka, SIL OFL) |
